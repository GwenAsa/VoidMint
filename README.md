## <img src="assets/icons/sparkles.svg" width="32" align="center"> The quiet side of Linux

> 🍃 *No noise. No bloat. Just forest.*

**VoidMint** is a custom desktop experience for **Void Linux + XFCE**.

🌿 Inspired by the independent spirit of **Void Linux**<br>
🍀 and the warm, familiar identity of **Linux Mint**,<br>
🌲 VoidMint brings a fresh visual direction to the traditional Linux desktop.

🌑 Deep forest backgrounds<br>
🌿 Muted sage accents<br>
🎨 Carefully coordinated icons<br>
🪶 Minimal interfaces

Every detail joins one cohesive environment, without turning a lightweight desktop into a heavyweight experience.

## <img src="assets/icons/download.svg" width="32" align="center"> Installation

> 🌲 Four steps. No systemd was harmed in the making of this desktop.

### 🧹 Step 0 · Sync your void

Every good Void story starts with a fresh package index:

```bash
sudo xbps-install -Su
```

### 📦 Step 1 · Gather the forest

Install the tools VoidMint builds on (package names may differ slightly, check `xbps-query -Rs <name>`):

```bash
sudo xbps-install -S git xfce4 xfce4-terminal rofi picom fastfetch starship papirus-icon-theme
```

Bibata cursors are not in every repo. See [`docs/DEPENDENCIES.md`](docs/DEPENDENCIES.md) for the manual install.

### 🌱 Step 2 · Plant the repo

```bash
git clone https://github.com/GwenAsa/VoidMint.git
cd VoidMint
```

### 🪄 Step 3 · Cast the spell

```bash
chmod +x scripts/install.sh
./scripts/install.sh
```

### 🚪 Step 4 · Step into the forest

Log out and log back in. The first login is the best part. 🌙

<img src="assets/icons/shield.svg" width="56" alt="">

**🛡️ Your existing configuration comes first.**<br>
<sub>The installer backs up everything before replacing a single file. Nothing is lost in the woods.</sub>

</div>

## <img src="assets/icons/history.svg" width="32" align="center"> Restoration

> 😅 Not your cup of tea? No hard feelings. Go back anytime.

```bash
./scripts/restore.sh
```

🔁 Your previous configuration comes back.<br>
💾 The currently installed VoidMint files are kept separately, so you can return to the forest later.
