# Dependencies

VoidMint is designed for Void Linux with the XFCE desktop environment.

## Required environment

- Void Linux (glibc)
- XFCE 4
- GTK 3
- Xfconf

## Desktop components

- Rofi
- Picom
- XFCE Terminal
- Fastfetch
- Starship

## External themes

These projects are dependencies, not original VoidMint assets:

- Papirus-Dark: https://github.com/PapirusDevelopmentTeam/papirus-icon-theme
- Bibata Cursor: https://github.com/ful1e5/Bibata_Cursor
